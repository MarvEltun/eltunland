YOUR CONNECTION

Make it personal.

Create your own API application, then save its credentials on this computer. Never paste secrets into a chat. Or skip the form: set STRAVA_CLIENT_ID, STRAVA_CLIENT_SECRET and STRAVA_REFRESH_TOKEN before starting the server.

  1. Open Strava API settings ↗ and register My Activities. Strava currently requires a subscription to register.
  2. Set the website to http://127.0.0.1:5173 and the Authorization Callback Domain to 127.0.0.1 (no port or path).
  3. Copy the Client ID and Client Secret below. You do not need to copy access or refresh tokens.

Saved in an owner-readable local database, not encrypted. Never expose this app to a network or publish its data folder.

Your API credentials are saved on this computer. For privacy, they are never returned to the browser.

You will be redirected to Strava to log in and approve read-only access. Keep “View data about your private activities” checked to include Only You activities.

Or connect with an existing access token

No new login is needed if your token already has activity:read or activity:read_all. Private activities require the latter. The token must have been authorized previously; this does not add permissions.

Stored only in the local, unencrypted credential database. Without a refresh token, it cannot renew automatically. Token validation reads your profile and checks one activity response without saving either response.

Connected with an imported access token. It cannot renew automatically. When it expires, import a new token or use Strava authorization.

What you're sharing

Your profile name and location, activity names, dates, sport, routes and available metrics such as distance, heart rate and power. Data is fetched directly from Strava when you browse. Private activities and privacy-zone data are included with your approval. No uploads or activity changes.

When you press Sync, a small summary of each activity (name, sport, date, distance, moving time and elevation) is saved on this computer so My Runs can total your training between races. Routes, heart rate and power are never saved. There is no background sync, analytics, AI processing or third-party map requests.

Disconnect below to revoke access and delete the local credentials and saved summaries. You can also revoke access in Strava settings ↗.

The second option does not revoke access on Strava. Use it if Strava is unreachable, then revoke access in your Strava settings.

Local by design.

This is a single-user app for your computer, not a hosted service. It connects only to Strava on your behalf. No tracking, analytics or AI features are included.

API credentials and refresh tokens persist in a local, owner-readable SQLite file, as do the activity summaries you sync (name, sport, date, distance, moving time, elevation). The file is not encrypted. Other activity and profile data, including routes, is not written to disk and is sent with no-store headers. It stays in page memory only while you browse. There is no service worker or offline activity cache.

Strava may collect API usage data under its API Policy. Their Privacy Policy applies to Strava's own processing.

For deletion, use Connection settings → Disconnect & delete local connection; it also deletes the synced summaries. You receive confirmation after deletion. If Strava cannot be reached, forget the local connection and revoke it in your Strava account.

Support: this is your self-hosted application. Setup, troubleshooting and maintenance instructions are in the project's README. No support service receives your information.

Map outlines: Natural Earth, public domain. No route coordinates are sent to map providers.
